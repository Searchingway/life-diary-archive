# 人生档案 Diary — 状态模型

## 总览

本应用共 **14 个数据模块**，每个模块有自己的状态、类型、优先级等枚举值。状态和类型均以字符串存储在 JSON 文件中，无数据库约束。

                              ↘ 搁置

                    ↘ 已转计划
                    ↘ 暂时搁置

                    ↘        ↘ 放弃

## 排序规则

各模块列表按以下权重排序：

| 模块 | 排序优先级 |
|------|----------|
| **轻计划** | `状态顺序` > `优先级` > `截止日期`（进行中 > 未开始 > 搁置 > 已完成；高 > 普通 > 低） |
| **行动计划** | 同上（进行中 > 未开始 > 暂停 > 已完成 > 放弃；高 > 普通 > 低） |
| **其他模块** | 按 `updated_at` 降序 |

### 排序常量

```python
# 轻计划排序
STATUS_ORDER = {"进行中": 0, "未开始": 1, "已完成": 2, "搁置": 3}
PRIORITY_ORDER = {"高": 0, "普通": 1, "低": 2}

# 行动计划排序
STATUS_ORDER = {"进行中": 0, "未开始": 1, "暂停": 2, "已完成": 3, "放弃": 4}
PRIORITY_ORDER = {"高": 0, "普通": 1, "低": 2}
```

## 数据约束

- 所有状态/类型均为**字符串字面量**，无数据校验层，无外键约束
- 存储层在 `save_*()` 中对状态和类型做**白名单校验**，非法值回退到默认值（如 `未开始`）
- 前端（React）和后端（`src/life_dairy/`）分别维护各自的常量定义，没有共享的 schema 文件
- 软删除独立于状态系统：`deleted: true` 标记后从 `list_*()` 中隐藏，不改变状态字段
