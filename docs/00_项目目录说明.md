# 项目目录说明

> 人生档案 (Life Diary) — 桌面端 + 安卓端个人记录应用

---

## 一、源码

| 路径 | 用途 |
|------|------|
| `main.py` | 桌面端入口，启动 `life_dairy` 应用 |
| `src/life_dairy/` | **桌面端核心源码**（PyQt6），按功能模块分为页面、存储、工具等 |
| `scripts/` | 构建与运行辅助脚本 |
| `scripts/personal/` | 个人辅助脚本（本机快捷命令，不建议提交 Git） |
| `scripts/build_windows.ps1` | Windows 打包脚本（PyInstaller + NSIS） |
| `scripts/run_diary.bat` | 开发时快速启动脚本 |
| `scripts/build_android.md` | 安卓构建步骤说明 |

> **不可清理，不可删除。** 这是项目核心，必须提交 Git。

---

## 二、测试

| 路径 | 用途 |
|------|------|
| `tests/` | 桌面端单元测试，覆盖各存储模块与页面逻辑 |
| `tests/__pycache__/` | 测试文件的字节码缓存 |

> `tests/` 源码不可删除；`tests/__pycache__/` 是自动生成的可清理缓存。
>
> 测试代码应提交 Git。

---

## 三、数据

| 路径 | 用途 |
|------|------|
| `data/` | 应用运行时用户数据（日记、计划、足迹等 JSON 文件） |

> **不可清理，不可删除。** 这是用户数据，不应提交 Git（已在 `.gitignore` 中忽略）。

---

## 四、文档

| 路径 | 用途 |
|------|------|
| `docs/` | 项目文档目录，含本文件 |
| `docs/dev-notes/` | 开发者笔记（如模块规划、技术债） |
| `docs/release/` | 构建发版文档 |
| `docs/release-notes/` | 版本发布说明 |
| `docs/test/` | 测试清单与验收文档 |
| `docs/test/05_测试清单.md` | 手动测试清单 |
| `docs/screenshots/` | 应用截图（桌面端 + 安卓端） |
| `README.md` | 项目总述、功能清单、使用说明 |
| `HANDOFF.md` | 交接文档（上下文传递用） |
| `TODO` | 待办事项 |
| `LICENSE` | 许可证 |
| `CHANGELOG.md`（如存在） | 版本历史（当前仅用 `release-notes/`） |

> **不可清理，不可删除。** 文档应提交 Git。

---

## 五、打包产出（桌面端）

| 路径 | 用途 |
|------|------|
| `packaging/windows/` | 安装包制作脚本与 PyInstaller spec 文件 |
| `packaging/windows/installer.py` | NSIS 安装器辅助脚本 |
| `packaging/windows/LifeDiary.spec` | PyInstaller 打包配置 |
| `packaging/windows/LifeDiaryInstaller.spec` | 安装器打包配置 |
| `pc_installer_work/` | PyInstaller 构建中间产物（临时） |
| `电脑直装版/` | 已构建好的免安装版（exe + 安装器） |

> - `packaging/windows/` 源码应**提交 Git**，不可删除。
> - `pc_installer_work/` 是构建中间产物，**可以清理**，不建议提交 Git。
> - `电脑直装版/` 是最终构建产物（exe/msi），**可以清理**（体积较大），不建议提交 Git（已在 `.gitignore` 中忽略）。

---

## 六、安卓端

| 路径 | 用途 |
|------|------|
| `android/LifeDiaryMobile/` | 安卓端完整源码（Qt for Android / Java） |
| `android/LifeDiaryMobile/build/` | 安卓构建产物（各 ABI、调试/发布） |
| `android_release.keystore` | 安卓签名文件 |
| `手机直装版/` | 已签名的 APK 安装包 |
| `.gradle-api27-home/` | Gradle 构建缓存与 daemon |

> - `android/LifeDiaryMobile/` 源码应**提交 Git**，不可删除。
> - `android/LifeDiaryMobile/build/` 是构建产物，**可以清理**，建议在 `.gitignore` 中忽略。
> - `android_release.keystore` 密钥文件**不可删除**，但**不应提交 Git**（已在 `.gitignore` 中忽略）。
> - `手机直装版/` 是 APK 产物，**可以清理**，不建议提交 Git（已在 `.gitignore` 中忽略）。
> - `.gradle-api27-home/` 是 Gradle 缓存（自动生成），**可以清理**，不应提交 Git。

---

## 七、工具与配置

| 路径 | 用途 |
|------|------|
| `.claude/` | Claude Code AI 辅助配置（记忆、设置、工作树） |
| `.claude/settings.local.json` | Claude Code 本地权限与钩子配置 |
| `.trae/` | Trae AI 编辑器配置 |
| `.idea/` | JetBrains IDE（PyCharm）项目配置 |
| `.vscode/` | VS Code 编辑器配置 |
| `.venv/` | Python 虚拟环境 |
| `pyproject.toml` | Python 项目元数据与依赖声明 |
| `requirements.txt` | Python 依赖列表（pip） |
| `.gitignore` | Git 忽略规则 |

> - 各 IDE 配置目录（`.idea/`、`.vscode/`）可保留个人习惯，**不建议提交 Git**（已在 `.gitignore` 中忽略）。
> - `.venv/` 是本地虚拟环境，**可以清理重建**，不应提交 Git。
> - `.claude/`、`.trae/` 视团队需要决定是否提交 Git；AI 辅助产生的记忆文件可选择性共享。
> - `pyproject.toml`、`requirements.txt`、`.gitignore` 必须提交 Git，不可删除。

---

## 八、临时缓存（均可清理）

| 路径 | 用途 | 清理建议 |
|------|------|----------|
| `__pycache__/` | Python 字节码缓存 | 随时可删，自动重建 |
| `src/life_dairy/__pycache__/` | 源码字节码缓存 | 随时可删，自动重建 |
| `tests/__pycache__/` | 测试字节码缓存 | 随时可删，自动重建 |
| `.pytest_cache/` | pytest 运行缓存 | 可删，不影响测试 |
| `.gradle-api27-home/` | Gradle 构建缓存 | 可删，下次构建自动下载 |
| `.tmp_testdata/` | 测试临时数据 | 可删，测试会自动重建 |
| `.venv/` | Python 虚拟环境 | 可删，`pip install -r requirements.txt` 重建 |
| `android/LifeDiaryMobile/build/` | 安卓构建产物 | 可删，Qt Creator 重新构建 |

> 以上目录均已在 `.gitignore` 中忽略，不会提交到 Git。

---

## 九、其他文件

| 路径 | 用途 |
|------|------|
| `app_icon .ico` | 桌面端应用图标（含空格的文件名，注意引用） |
| `assets/icons/` | 图标资源（app_icon.ico / jpg / life_diary_icon.ico） |
| `scripts/personal/run_claude_deepseek_flash.bat` | 启动 Claude Code 的快捷批处理（个人辅助） |

> `assets/` 是资源文件，应提交 Git，不可删除。`scripts/personal/run_claude_deepseek_flash.bat` 是个人快捷方式，不建议提交 Git。
