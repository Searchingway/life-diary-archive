# 项目目录说明

当前目录、应用和数据规则请以 [CURRENT.md](CURRENT.md) 为准；本文件只说明导航。

- `diary_v2.0/`：当前 Windows 桌面应用。
- `mobile/`：当前 Expo / React Native 移动应用。
- `src/life_dairy/`：被桌面端导入的冻结兼容核心，不能整体迁走。
- `legacy/`：不再维护的 Qt Android 与 PySide6 UI 历史内容。
- `docs/archive/`：历史文档，不代表当前实现。
- `data/`、`diary_v2.0/data/`：真实用户数据，禁止提交、迁移或删除。
