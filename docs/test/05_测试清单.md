# 测试清单 — Desktop 3.2 信息备忘模块

## 新增测试项

### 基础 CRUD
- [ ] 新建接单记录：选择类型「接单记录」，填写客户、中介、执行人、报价等信息，能成功创建草稿
- [ ] 保存接单记录：填写完整后点击保存，状态栏提示已保存
- [ ] 重新打开后数据仍存在：关闭程序后重新打开，已保存的信息卡片出现在列表中
- [ ] 新建网课资源：选择类型「网课资源」，填写课程名称、平台、链接等信息
- [ ] 保存课程链接和平台：保存后重新打开，课程链接和平台字段正常显示
- [ ] 新建通用信息：选择类型「通用信息」，填写分类和主要内容
- [ ] 删除信息卡片：点击删除，确认后从列表中移除

### 搜索
- [ ] 搜索标题：在搜索框输入标题关键字，列表过滤正确
- [ ] 搜索客户 / 中介 / 课程平台：在搜索框输入客户名、中介名或课程平台，能搜索到对应记录

### 筛选
- [ ] 按类型筛选：选择「接单记录」/「网课资源」/「通用信息」，列表只显示对应类型
- [ ] 按状态筛选：选择特定状态，列表只显示对应状态的记录
- [ ] 类型筛选联动状态筛选：选择类型后，状态筛选下拉只显示该类型可用的状态

### 导航与集成
- [ ] 顶部导航能正常切换：点击「信息备忘」页签，页面正常显示；切换到其他页签再切回，数据正常
- [ ] 总览页能看到最近的信息备忘：总览页时间线中包含信息备忘记录，模块统计中显示信息备忘数量

### 自动保存
- [ ] 自动保存不跳光标：在编辑器中输入文字，等待 3 秒后自动保存，光标位置不发生变化
- [ ] 未保存内容切换提示：有未保存修改时切换页签，自动保存成功后允许切换

### 兼容性
- [ ] 旧模块不受影响：日记、足迹、轻计划、轻思考、轻资源、自我观察、教训与反思、自我分析、作品感悟等原有模块功能正常
- [ ] 数据管理：备份/恢复包含 info_memos/ 目录

## 笔记功能测试项

### 基础 CRUD
- [ ] 新建笔记：点击「新建笔记」，三个输入框清空，处于可编辑状态
- [ ] 保存笔记：填写标题、描述、正文后点击保存，列表中出现新条目
- [ ] 重新打开后数据仍存在：关闭程序后重新打开，已保存的笔记出现在列表中
- [ ] 删除笔记：点击删除，确认后从列表中移除
- [ ] 恢复已保存内容：修改后点击「恢复已保存内容」，内容恢复到上次保存状态

### 搜索
- [ ] 搜索标题：在搜索框输入标题关键字，列表过滤正确
- [ ] 搜索描述和正文：搜索框可匹配描述和正文内容

### 自动保存
- [ ] 自动保存：输入文字后等待 3 秒，内容自动落盘
- [ ] 空白笔记不会自动保存：新建后不填写内容，不会创建存储文件
- [ ] 未保存内容切换提示：有未保存修改时切换页签，自动保存后允许切换

### 导航与集成
- [ ] 笔记页签标题随未保存状态变化：有修改时标签显示「笔记 *」
- [ ] 总览页能看到最近的笔记：总览页时间线中包含笔记记录
- [ ] 数据管理备份/恢复包含 notes/ 目录
