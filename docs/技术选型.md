# 技术选型

当前技术栈与应用边界以 [CURRENT.md](CURRENT.md) 为准。

- 桌面端：`diary_v2.0/`，React SPA + Python `ThreadingHTTPServer` + PySide6 壳；数据为本地 JSON 文件树。
- 移动端：`mobile/`，Expo SDK 56、React Native、Expo SQLite；完整 ZIP 备份和 Desktop Canonical 同步保持兼容。
- 兼容层：`src/life_dairy/` 仅提供桌面端仍依赖的 Storage、Models、Export 和 AI 能力，旧 PySide6 页面冻结。

不要把历史 Qt Android 或旧 PySide6 Widgets 当成当前产品技术栈。
