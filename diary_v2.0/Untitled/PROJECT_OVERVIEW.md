# 人生档案 Diary - 项目概览

## 应用简介

"人生档案 Diary" 是一个本地优先的个人档案和规划工作台桌面应用。使用 React + Tailwind CSS 构建,专为桌面使用体验优化(1440×900 或 1500×900)。

## 核心特性

- ✅ **本地优先**: 所有数据存储在本地,无云同步,无账户登录
- ✅ **AI 辅助**: AI 可生成草稿,但必须经用户预览确认才能应用
- ✅ **清晰导航**: 桌面风格侧边栏导航,功能模块分组清晰
- ✅ **分离式设计**: 查看、编辑和执行功能分离,避免密集表单

## 已实现的功能模块

### 1. 总览
- **Dashboard / 工作台**: 展示今日任务、进行中的行动计划、最近动态、统计数据和模块概览

### 2. 日常记录
- **Diary / 日记**: 以写作为中心的日记编辑器,支持图片、关联足迹、导出 Word/PDF
- **Footprints / 足迹**: 两级结构(地点 → 访问记录),支持地点描述、访问感想、关联日记
- **Self Observation / 自我观察**: 快速记录情绪、强度、触发事件、身体感受

### 3. 思考与反思
- **Light Thought / 轻思考**: 渐进式思考记录,支持问题描述、思考时间线、结论和下一步行动
- **Light Resource / 轻资源**: 多维度资源评估(时间、金钱、精力、情绪、勇气、身体、注意力、风险、机会成本)
- **Lessons & Reflection / 教训与反思**: 结构化反思记录,包含事件、判断失误、真正问题、付出代价、下次策略
- **Self Analysis / 自我分析**: 深度个人分析,涵盖触发事件、情绪、身体反应、真正恐惧、重复模式等12个分析维度

### 4. 计划与执行
- **Light Plan / 轻计划**: 低压力计划捕获,支持增量计划和减量计划,可转为行动计划
- **Action Plan / 行动计划**: 完整的执行工作台
  - **时间表视图**: 按日期分组的任务卡片,今日任务高亮
  - **任务链视图**: 深色画布风格的可视化任务地图,类似技能树

### 5. 信息与作品
- **Info Memo / 信息备忘**: 管理重要信息
  - 自由职业订单(客户、价格、定金、尾款、工期、交付物)
  - 在线课程
  - 通用信息
- **Works / Media Reflection / 作品感悟**: 记录书籍、影视、课程等作品的个人感悟,支持摘抄笔记(可折叠)

### 6. 系统
- **Data Management / 数据管理**: 
  - 数据位置显示
  - 备份和恢复功能
  - 移动端 ZIP 导入(自动备份、ID 合并)
  - 桌面端 ZIP 导出
  - 模块数据统计
  - 数据健康检查
- **AI Settings / AI 设置**: 
  - 启用/禁用 AI 功能
  - DeepSeek API 配置
  - API Key 安全管理(支持显示/隐藏)
  - 连接测试
  - 安全提示说明

## 技术栈

- **React 18.3.1**: UI 框架
- **React Router 7.13.0**: 路由管理
- **Tailwind CSS 4.1.12**: 样式系统
- **Radix UI**: 无障碍 UI 组件库
- **Lucide React**: 图标库
- **TypeScript**: 类型安全

## 设计原则

1. **查看与编辑分离**: 主页面用于查看和执行,创建/编辑使用模态框或侧面板
2. **写作优先**: 日记、反思、分析等页面给予充足的写作空间
3. **避免密集表单**: 使用卡片式布局展示信息,避免数据库式的表单页面
4. **桌面体验**: 针对桌面使用优化,不是移动优先
5. **本地安全**: 所有敏感数据本地存储,API Key 安全管理

```

/light-thought         → 轻思考
/light-resource        → 轻资源
/lessons-reflection    → 教训与反思
/self-analysis         → 自我分析
/light-plan            → 轻计划
/action-plan           → 行动计划
/info-memo             → 信息备忘
/works-reflection      → 作品感悟

```

## UI 特色

- **侧边栏导航**: 功能模块按逻辑分组,每组有明确的视觉分隔
- **卡片式布局**: 使用卡片组织相关信息,视觉层次清晰
- **状态指示**: 实时显示本地数据状态、保存状态等
- **快速操作**: Dashboard 提供常用功能的快速入口
- **进度可视化**: 行动计划支持进度条和任务链可视化
- **智能折叠**: 次要内容(如图片、摘抄)支持折叠,不占用主要空间

## 如何使用

应用已配置 React Router,侧边栏导航可以在各个功能模块间切换。每个模块都有:
- 左侧列表区域(搜索、筛选、项目列表)
- 主内容区域(查看和编辑)
- 操作按钮(新建、编辑、关联、AI 辅助等)

所有数据当前使用模拟数据,可以在实际使用时连接真实的数据源。
